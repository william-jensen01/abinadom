Create `scripts/verify_pipeline.py` with the following structure. Per D-08, this must be a reusable script. Per D-09, it writes JSON to `data/verification_report.json` and prints human-readable stdout.

**Script boilerplate** (match run_audit.py pattern):

**Imports:**

**argparse:** Accept `--output PATH` (default `data/verification_report.json`) to customize report path.

**VER-01: `check_counts(client, ef)`** (per D-03):
- Derive expected talk count from SQLite at runtime: `core_db.select("SELECT COUNT(*) as cnt FROM talk t INNER JOIN conference_talk ct ON ct.TalkID = t.ID")` -> `rows[0]["cnt"]`
- Get SQLite citation baseline: `core_db.select("SELECT COUNT(*) as cnt FROM citation")` -> `rows[0]["cnt"]`
- Compare `conference_talks.count()` against SQLite GC count -- MUST match exactly (hard pass/fail)
- `conference_talk_paragraphs.count()` must be > 0 (no SQLite baseline)
- `conference_talk_citations.count()` > 0; log delta against SQLite citation count as informational (not failure)
- `conference_talk_footnotes.count()` > 0 (no SQLite baseline)
- Check if `data/failed_talks.json` exists; if so, load and report count (per CONTEXT specifics)
- Print one-line `VER-01: Count verification ... PASS/FAIL` then indented details per collection
- Return dict matching JSON schema: `{"passed": bool, "counts": {...}, "failed_talks_file": ...}`

**VER-02: `check_semantic_search(client, ef)`** (per D-04, D-05):
- Get `conference_talk_paragraphs` collection WITH `embedding_function=ef` (CRITICAL per Pitfall 2)
- Get `conference_talks` collection WITH `embedding_function=ef` (for talk metadata lookups)
- Run 5 queries:
  1. `"the Atonement of Jesus Christ forgiveness of sins"`
  2. `"eternal family temple covenants"`
  3. `"faith and repentance turning to God"`
  4. `"Mosiah 3:19 natural man enemy to God"`
  5. `"John 3:16 God so loved the world"`
- For each query: `paras.query(query_texts=[q], n_results=5, include=["documents", "metadatas", "distances"])`
- For each result, extract `talk_id` from metadata, then look up talk metadata via `talks_col.get(ids=[f"talk_{talk_id}"])` to get `speaker_name`, `conference_year`, `title`
- Print formatted output: `talk_id | speaker_name | conference_year | title` then `Para: text[:150]`
- Wrap in try/except: if Ollama is down, mark VER-02 as `{"skipped": true, "reason": "Ollama unavailable"}` not FAIL
- Print `VER-02: Semantic search ... (manual review required)` or `VER-02: Semantic search ... SKIPPED`
- Return dict with query results for JSON report

**VER-03: `check_metadata_filters(client, ef)`** (per D-06, Research VER-03 Filter Design):
- Get `conference_talks` collection (per Research: paragraphs lack speaker/year/session fields)
- Run 4 filter tests on `conference_talks`:
  1. `where={"speaker_name": "Russell M. Nelson"}` -- expect >= 100 results
  2. `where={"conference_year": 2023}` -- expect > 0
  3. `where={"session_abbr": "Saturday Morning"}` -- expect > 0
  4. Compound: `where={"$and": [{"speaker_name": "Russell M. Nelson"}, {"conference_year": 2023}]}` -- expect > 0
- Two-step paragraph-level filter demonstration (per D-06 and Research):
  1. Get talk_ids from `conference_talks` where `speaker_name = "Russell M. Nelson"` and `conference_year = 2023`
  2. Filter `conference_talk_paragraphs` by those `talk_id` values using `where={"talk_id": {"$in": talk_ids}}`
  3. Report paragraph count
- Each filter: PASS if count > 0, FAIL if count == 0
- Print `VER-03: Metadata filter ... PASS/FAIL` then indented per-filter counts
- Return dict with filter results

**VER-04: `check_fk_integrity(client, ef)`** (per D-07, Research Pattern 4):
- Build reference sets:
  - `talk_ids_set`: all IDs from `conference_talks.get(limit=10000, include=[])["ids"]` -> strip "talk_" prefix -> int set
  - `para_ids_set`: all IDs from `conference_talk_paragraphs.get(limit=250000, include=[])["ids"]` (IDs-only bulk get is safe per Research)
- **Paragraphs -> Talks FK:** Page through paragraphs metadata in batches of 5000 (per Research Pattern 4 -- `get(limit=5000, offset=N, include=["metadatas"])`). Extract `talk_id` from each metadata dict. Check every `talk_id` exists in `talk_ids_set`. Use tqdm progress bar. Count orphans.
- **Citations -> Paragraphs FK:** Page through citations metadata in batches of 5000. Extract `paragraph_id`. Check against `para_ids_set`. Note: annotation-sourced citations may have paragraph_ids NOT in `conference_talk_paragraphs` -- this is expected by design (Pitfall 6). Count unresolvable but mark as informational.
- **Footnotes -> Talks FK:** Page through footnotes metadata in batches of 5000. Extract `talk_id`. Check against `talk_ids_set`. Count orphans.
- Print `VER-04: FK integrity ... PASS/FAIL` then indented scan results
- Return dict with scan counts and orphan counts

**Main function:**
- Parse args
- Initialize: `client = get_chromadb_client()`, `ef = get_embedding_function()`
- Run checks in order: VER-01, VER-02, VER-03, VER-04
- Build overall report dict:
  ```python
  {
      "run_timestamp": datetime.datetime.now().isoformat(),
      "ver_01": ver01_result,
      "ver_02": ver02_result,
      "ver_03": ver03_result,
      "ver_04": ver04_result,
      "overall_passed": ver01_passed and ver03_passed and ver04_passed
  }
  ```
  Note: VER-02 is manual review, so overall_passed excludes it.
- Write JSON report: `json.dump(report, f, indent=2, ensure_ascii=False)` with `encoding="utf-8"`
- Print overall summary: `Overall: N/3 automated checks PASS | VER-02: manual review`

main()
