    **Problem:** In `server.py`, `_check_ollama()` calls `get_embedding_function()` with no arguments (line 94). This means `get_embedding_function` reads `OLLAMA_URL` from `os.environ` independently. Meanwhile, `_resolve_ollama_url()` also reads `OLLAMA_URL` from `os.environ` but is only used for the error message (line 106). If defaults ever diverge, the error message URL and actual connection URL would differ.

    **Fix in server.py `_check_ollama()` function (lines 85-109):**

    Change line 94 from:
    ```python
        ef = get_embedding_function()
    ```
    to:
    ```python
        ollama_url = _resolve_ollama_url()
        ef = get_embedding_function(url=ollama_url)
    ```

    And change line 106 from:
    ```python
                f"ERROR: Ollama unreachable at {_resolve_ollama_url()}. Start Ollama and retry.",
    ```
    to:
    ```python
                f"ERROR: Ollama unreachable at {ollama_url}. Start Ollama and retry.",
    ```

    This makes `_resolve_ollama_url()` the single source of truth: it resolves the URL once, passes it to `get_embedding_function(url=...)` for the actual connection, and uses the same value in the error message. No second independent env read.

    **Do NOT modify `extractors/phase6_chromadb_loader.py`.** The `get_embedding_function()` there still needs its own `OLLAMA_URL` fallback for pipeline callers that don't go through server.py. The consolidation is specifically about server.py always using its own resolver.

    **Test update in tests/test_server.py:**

    Find the `test_ollama_url_env_override` test. It currently tests that `get_embedding_function` picks up the env var. After this change, we need to verify that `_check_ollama()` passes the resolved URL through. Add or update a test:

    ```python
    def test_check_ollama_passes_resolved_url(monkeypatch):
        """_check_ollama passes _resolve_ollama_url() result to get_embedding_function(url=...)."""
        monkeypatch.setenv("OLLAMA_URL", "http://custom-host:9999")
        captured_url = {}

        original_get_ef = get_embedding_function
        def mock_get_ef(url=None):
            captured_url["url"] = url
            mock_ef = lambda texts: [[0.1] * 10]
            return mock_ef

        monkeypatch.setattr("server.get_embedding_function", mock_get_ef)
        _check_ollama()
        assert captured_url["url"] == "http://custom-host:9999"
    ```

    Import `_check_ollama` at the top of test_server.py if not already imported. The existing imports line likely has `from server import ...` — add `_check_ollama` to that import list.

    Run `pipenv run py -m pytest tests/test_server.py -x -q` to confirm all tests pass (existing 37 + 1 new = 38).
