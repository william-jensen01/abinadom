# Requirements: BYU Scripture Citation Index RAG System

**Defined:** 2026-03-30
**Milestone:** v2.0 MCP Server
**Core Value:** All LDS content searchable by meaning — find how scriptures are cited, applied, and discussed across decades of conference talks and discourse, with full referential integrity between talks, paragraphs, citations, and footnotes.

## v2.0 Requirements

### Foundation

- [x] **CORE-01**: Server resolves ChromaDB path to absolute at startup (prevents silent empty-DB creation when Claude Desktop spawns with unknown working directory)
- [x] **CORE-02**: Server performs Ollama health check at startup and fails fast with a clear error if unreachable
- [x] **CORE-03**: Server warms up all 4 ChromaDB collections at startup before accepting tool calls
- [x] **CORE-04**: User can pass informal speaker names ("Holland", "Elder Holland") and server resolves to canonical form ("Jeffrey R. Holland")
- [x] **CORE-05**: User can pass informal year/season values ("2020", "April 2020") and server normalizes to structured metadata filters
- [x] **CORE-06**: User can pass collection aliases ("talks", "paragraphs", "citations", "footnotes") that resolve to internal ChromaDB collection names

### Tools

- [x] **TOOL-01**: User can perform semantic search across any of the 4 collections with a natural language query
- [x] **TOOL-02**: User can filter search results by speaker, year, conference season, and/or collection
- [x] **TOOL-03**: Search returns readable snippet text (no internal pipeline fields), default 5 results, max 20
- [x] **TOOL-04**: User can retrieve full ordered text of a talk by talk ID
- [x] **TOOL-05**: `get_talk` returns paragraphs sorted by narrative position (position field)

### Integration

- [x] **INTG-01**: MCP server runs via stdio transport; all logging goes to stderr only (no stdout pollution)
- [x] **INTG-02**: User can connect to the MCP server from Claude Desktop via `claude_desktop_config.json` with absolute virtualenv path
- [x] **INTG-03**: Claude engages with LDS content conversationally via a system prompt that establishes its role as an informed discussion partner
