<objective>
Fix Bug 1: ChromaDBLoader.query() queries a phantom empty collection instead of the loaded data.

Purpose: query() calls get_or_create_collection(name=collection) with a raw short-key like
"paragraphs". load() resolves through CHROMADB_COLLECTION_NAMES to store into
"conference_talk_paragraphs". The mismatch means query() auto-creates and hits a new empty
collection, returning no IDs. The _collect_chroma_baseline() caller in runner.py then skips all
queries (if not baseline_ids: continue), leaving k10_scores = [] and returning 0.0.

Output: loaders/chromadb_loader.py with a single one-line fix in query() that mirrors the
collection name resolution already done in load().
</objective>
