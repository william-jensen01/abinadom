### CR-01: Weaviate query() name_map fallback — no validation for unknown collection names

**File:** `loaders/weaviate_loader.py:284`
**Commit:** `429564c` — fix(22.1): CR-01 add validation for unknown collection name in Weaviate query()
**Applied fix:** After `class_name = name_map.get(collection, collection)`, inserted a guard that raises a descriptive `ValueError` when `class_name` is not one of the four known Weaviate class names (`Talk`, `Paragraph`, `Citation`, `Footnote`). ### CR-02: Benchmark run_recall() skips empty baselines, biasing recall scores

**File:** `benchmark/runner.py:468-470`
**Commit:** `b2a3fdb` — fix(22.1): CR-02 include empty baselines in recall mean to avoid statistical bias
**Applied fix:** Removed the `if not baseline_ids: continue` guard. Empty baselines now contribute `recall=0.0` to `k10_scores` and `k50_scores`, keeping the denominator consistent across all N canonical queries and eliminating the artificial inflation of the reported mean recall.
