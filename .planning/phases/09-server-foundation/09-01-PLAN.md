    - `DEFAULT_PATH = Path(__file__).parent.resolve() / "data" / "chromadb"`

    **_check_ollama() -> None:** (CORE-02, per D-04)
    - Call `get_embedding_function()` to get the embedding fn
    - Call `ef(["health check"])` to do a live embedding
    - Wrap in try/except Exception as e
    - On exception: inspect `str(e)` — if contains "nomic-embed-text" or "model" (case insensitive), print to stderr: `"ERROR: Ollama model not available. Run: ollama pull nomic-embed-text"`
    - Otherwise print to stderr: `"ERROR: Ollama unreachable at http://localhost:11434. Start Ollama and retry."`
    - Call `sys.exit(1)` on any failure
    - On success: `logger.info("Ollama health check passed (nomic-embed-text ready)")`

    **_load_collections(client: chromadb.ClientAPI) -> dict:** (CORE-03, per D-05)
    - Iterate `CHROMADB_COLLECTION_NAMES.items()` (key, name pairs)
    - For each: `client.get_collection(name=name)` — NOT `get_or_create_collection()`
    - On exception: `print(f"ERROR: ChromaDB collection '{name}' not found. Run the pipeline (scripts/run_pipeline.py) first.", file=sys.stderr)` then `sys.exit(1)`
    - Check `col.count()` — if 0: `print(f"ERROR: Collection '{name}' exists but has 0 records. Re-run the pipeline to populate it.", file=sys.stderr)` then `sys.exit(1)`
    - On success: `logger.info("Loaded collection '%s' (%d records)", name, count)`
    - Return dict mapping key -> collection

    **_startup() -> AppContext:**
    - Call `_resolve_chromadb_path()` to get path
    - Validate path exists: `if not Path(path).exists(): print(f"ERROR: ChromaDB directory not found at {path}", file=sys.stderr); sys.exit(1)`
    - Create client: `chromadb.PersistentClient(path=path)`
    - Call `_check_ollama()`
    - Call `_load_collections(client)` to get collections dict
    - Return `AppContext(client=client, collections=collections)`

    **Lifespan (CORE-03 integration):**
    ```python
    @asynccontextmanager
    async def lifespan(server: FastMCP):
        try:
            ctx = _startup()
        except SystemExit:
            raise
        except Exception as e:
            print(f"ERROR: Unexpected startup failure: {e}", file=sys.stderr)
            sys.exit(1)
        try:
            yield ctx
        finally:
            pass  # ChromaDB PersistentClient needs no explicit close
    ```

    mcp = FastMCP("lds-scripture-index", lifespan=lifespan)
