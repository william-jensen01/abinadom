  <action>
Add a `reset(host, port, ...)` classmethod to each loader. The reset method:
1. Creates a temporary client (same constructor args as __init__)
2. Iterates over the same collection/class names used in __init__
3. Calls the delete API for each, swallowing NotFound errors (collection may not exist on first run)
4. Closes the temporary client
5. Returns (does NOT call __init__ — caller will instantiate a fresh loader after reset)

Use a classmethod (not instance method) so it can be called before instantiation in main().
The reset logic must NOT call __init__ internally — that would double-create connections.

**ChromaDB (loaders/chromadb_loader.py):**
Add after the `close()` method:

```python
@classmethod
def reset(cls, host: str, port: int) -> None:
    """Delete all 4 benchmark collections from ChromaDB (per D-02).

    Swallows NotFound — safe to call on a fresh stack.
    Caller must instantiate a new ChromaDBLoader after this returns.
    """
    client = chromadb.HttpClient(host=host, port=port)
    try:
        for name in CHROMADB_COLLECTION_NAMES.values():
            try:
                client.delete_collection(name)
                logger.info("ChromaDB: deleted collection %r", name)
            except Exception as e:
                logger.debug("ChromaDB: delete_collection(%r) skipped: %s", name, e)
    finally:
        try:
            client.close()
        except Exception:
            pass
```
