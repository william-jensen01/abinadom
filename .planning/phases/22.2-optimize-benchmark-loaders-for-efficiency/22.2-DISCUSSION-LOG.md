**Context:** `runner.py` already has `--workers` (default=10) for query concurrency. SPEC Req 4 adds upsert parallelism on `--workers` with default=4. These conflict.

| Question | Options presented | Selection |
|---|---|---|

**Outcome:** `--workers` default changes from 10 → 5. One flag for both upsert and query concurrency. Scalability curve unchanged.

## Area 3: Thread-local loader lifecycle

**Context:** ThreadPoolExecutor(max_workers=5) needs one loader per thread (not one per talk). Weaviate gRPC connections are expensive; reuse across talks per thread.

| Question | Options presented | Selection |
|---|---|---|
| How to give each thread its own loader? | Per-thread via initializer / Per-talk (create+close per task) | **Per-thread via initializer** |
| How to close thread-local loaders? | atexit.register in initializer / Track list, close after pool | **atexit.register in initializer** |

**Outcome:** `ThreadPoolExecutor(initializer=_init_worker, initargs=(db_name, args))`. `_tls = threading.local()`. `atexit.register(loader.close)` in initializer — mirrors embeddings.py pattern.
