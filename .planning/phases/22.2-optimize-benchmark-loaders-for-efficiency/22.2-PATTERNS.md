**Analog:** `loaders/embeddings.py` (extend in place)

**Existing singleton + atexit pattern** (lines 19–24):

**Existing `embed()` as structural template** (lines 27–50):
```python

    text: str,
    model: str = "nomic-embed-text",
    url: str = OLLAMA_URL,
) -> list[float]:
    response = _client.embed(model=model, input=text)
    # EmbedResponse.embeddings: Sequence[Sequence[float]]
```

**New `embed_batch()` to add** — mirror `embed()` exactly but accept `list[str]` and return `list[list[float]]`:
```python
def embed_batch(
    texts: list[str],
    model: str = "nomic-embed-text",
    url: str = OLLAMA_URL,
) -> list[list[float]]:
    """
    Return a list of 768-dim float vectors from Ollama nomic-embed-text.
    Sends all texts in a single HTTP round-trip via Ollama batch embed API.

    Args:
        texts: Input texts to embed (list of strings).
        model: Ollama model name. Default "nomic-embed-text" (768 dims).
        url:   Ollama server URL. Default http://localhost:11434.

    Returns:
        list[list[float]], one vector per input text, same order.
    """
    response = _client.embed(model=model, input=texts)
    return [list(v) for v in response.embeddings]
```

**Key constraint:** `embed()` (single-text) must remain unchanged — backward compatibility for any non-benchmark callers.

### `loaders/shared_transforms.py` — batch embed refactor

**Analog:** `loaders/shared_transforms.py` (self — refactor `prepare_talk_bundle` and `prepare_talk_bundle_rich`)

**Current `embed_fn` type annotation pattern** (appears in 8 function signatures, e.g. lines 95, 143, 197, 237, 278, 299, 324, 341):
```python

```
All 8 occurrences must change to:
```python
embed_fn: Callable[[list[str]], list[list[float]]] | None = None
```

**Current per-record embed call pattern** (repeated across all `prepare_*` helpers, e.g. line 137, 188, 228, 263, 292, 316, 333, 349):
```python
vector = embed_fn(document) if embed_fn is not None else None
```
After the refactor, individual helpers **no longer call `embed_fn` themselves**. Instead, they return `None` for vector and accept pre-computed vectors passed in from the bundle-level function.

**Collect-embed-distribute pattern for `prepare_talk_bundle`** (lines 359–418, replace body):

The pattern: gather all `document` strings from every record across all four helper calls into one list, call `embed_fn(texts)` once to get a vector per position, then zip vectors back to records by index.

```python
def prepare_talk_bundle(
    metadata: TalkMetadata,
    paragraphs: TalkParagraphs,
    citations: TalkCitations,
    footnotes: TalkFootnotes,
    validation_report: ValidationReport,
    embed_fn: Callable[[list[str]], list[list[float]]] | None = None,
) -> dict[str, list[tuple[str, dict[str, Any], str, list[float] | None]]]:
    if not validation_report.is_valid:
        logger.warning(
            "Skipping talk_id=%s — failed validation. Errors: %s",
            metadata.talk_id,
            validation_report.errors,
        )
        return {"talks": [], "paragraphs": [], "citations": [], "footnotes": []}

    # Phase 1: prepare all records WITHOUT embedding (embed_fn=None)
    paragraph_records, annotation_texts = prepare_paragraph_records(
        paragraphs, talk_metadata=metadata, embed_fn=None
    )
    talk_record = prepare_talk_record(metadata, annotation_texts, embed_fn=None)
    citation_records = prepare_citation_records(citations, embed_fn=None)
    footnote_records = prepare_footnote_records(footnotes, embed_fn=None)

    all_records = [talk_record] + paragraph_records + citation_records + footnote_records

    # Phase 2: batch-embed all documents in one call
    if embed_fn is not None:
        texts = [doc for doc, _meta, _id, _vec in all_records]
        vectors = embed_fn(texts)
        all_records = [
            (doc, meta, doc_id, vec)
            for (doc, meta, doc_id, _), vec in zip(all_records, vectors)
        ]

    # Phase 3: redistribute back into per-collection lists
    n_talk = 1
    n_para = len(paragraph_records)
    n_cite = len(citation_records)
    talk_recs = all_records[:n_talk]
    para_recs = all_records[n_talk:n_talk + n_para]
    cite_recs = all_records[n_talk + n_para:n_talk + n_para + n_cite]
    fn_recs   = all_records[n_talk + n_para + n_cite:]

    return {
        "talks": talk_recs,
        "paragraphs": para_recs,
        "citations": cite_recs,
        "footnotes": fn_recs,
    }
```

Apply the identical collect-embed-distribute pattern to `prepare_talk_bundle_rich` (lines 421–471), using the `_prepare_*_rich` helpers with `embed_fn=None` in phase 1.

**Note on Claude's Discretion (CONTEXT.md):** Whether to share a single batching helper or inline the collect-embed-distribute loop in each bundle function is left to the implementer. Inlining is simpler and avoids a new abstraction layer.

```python
for key, class_name in collection_map.items():
```

```python
    objects = [
        DataObject(
            properties={**meta, "doc_id_str": doc_id},
```

### Query Method Embed Adapter
**Applies to:** `loaders/weaviate_loader.py` `query()` (line 293), `loaders/qdrant_loader.py` `query()`, `loaders/chromadb_loader.py` `query()`

The `query()` methods call `self.embed_fn(query_text)` with a single string. After `embed_fn` changes to `Callable[[list[str]], list[list[float]]]`, all `query()` calls must adapt:
```python
# Current (line 293 in weaviate_loader.py):
query_embedding = self.embed_fn(query_text)

# Target (unwrap single-item batch):
query_embedding = self.embed_fn([query_text])[0]
```
This pattern applies identically to `qdrant_loader.py` and `chromadb_loader.py` query methods. Query methods are "out of scope" per SPEC but the signature change forces this mechanical update.

### WARNING-level Error Logging (no crash)
