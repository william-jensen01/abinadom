# Phase 22.2 Plan 01: Add embed_batch() Batch Embedding Function — Summary

**One-liner:** Added `embed_batch(texts: list[str]) -> list[list[float]]` to `loaders/embeddings.py` using Ollama's batch embed API, collapsing 80-100 sequential HTTP calls per talk bundle into one round-trip.

## What Was Built

`loaders/embeddings.py` now exports two functions:

- `embed(text: str) -> list[float]` — unchanged single-text embedding (backward compatible)
- `embed_batch(texts: list[str]) -> list[list[float]]` — new batch embedding via one Ollama call

Both functions share the module-level `_client` singleton (`ollama.Client(host=OLLAMA_URL)`). The `embed_batch` implementation delegates to `_client.embed(model=model, input=texts)` (list input triggers Ollama's batch path) and materializes the result as `[list(v) for v in response.embeddings]`.

The module docstring was updated to include the `embed_batch` import example alongside the existing `embed` example.
