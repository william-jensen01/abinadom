# Phase 22.2 Plan 02: shared_transforms.py Batch Embedding Refactor — Summary

**One-liner:** Refactored `prepare_talk_bundle()` and `prepare_talk_bundle_rich()` to use a collect-embed-distribute pattern, cutting Ollama HTTP calls from O(n_records) to exactly 1 per bundle.

## What Was Built

`loaders/shared_transforms.py` was updated in two steps:

1. All 10 `embed_fn` type annotations changed from `Callable[[str], list[float]]` to `Callable[[list[str]], list[list[float]]]` — covering 8 individual helper signatures plus the 2 bundle function signatures.

2. Both `prepare_talk_bundle()` and `prepare_talk_bundle_rich()` now use the collect-embed-distribute pattern:
   - **Phase 1 (collect):** Call all individual helpers with `embed_fn=None`, gather all records without embedding
   - **Phase 2 (embed):** Call `embed_fn(texts)` once with all documents in the bundle
   - **Phase 3 (distribute):** Zip vectors back to records using index slicing

Individual helper functions retain their per-record `embed_fn` paths for backward compatibility when called directly by non-bundle callers.
