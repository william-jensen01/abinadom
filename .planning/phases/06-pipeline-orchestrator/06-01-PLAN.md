Create `scripts/run_pipeline.py` implementing the full pipeline orchestrator. Follow the skeleton from 06-RESEARCH.md Pattern 1 closely. Specific requirements:

**Imports and setup (per D-09, matching run_audit.py pattern):**
- `sys.path.insert(0, str(Path(__file__).parent.parent))` at top
- `from tqdm import tqdm`
- `from db import content_db, core_db`
- `from config.schemas import PARAGRAPH_CONFIG`
- `from config.pipeline_config import CHROMADB_BATCH_SIZE, CHROMADB_COLLECTION_NAMES`
- `from extractors.pipeline import process_talk_pipeline`
- `from extractors.phase3_citation_extraction import fetch_all_books`
- `from extractors.phase5_validation import validate_talk`
- `from extractors.phase6_chromadb_loader import get_chromadb_client, get_embedding_function, load_talk_bundles, TalkBundle`
- `logger = logging.getLogger(__name__)`
- `FAILED_TALKS_PATH = Path(__file__).parent.parent / "data" / "failed_talks.json"`

**_get_all_gc_talk_ids() function:**
- Query: `SELECT t.ID FROM talk t INNER JOIN conference_talk ct ON ct.TalkID = t.ID ORDER BY t.ID`
- Use `core_db.select(...)` which returns list of Row dicts
- Return `[row["ID"] for row in rows]`
- CRITICAL: Must INNER JOIN conference_talk to get only GC talks (5,838), NOT all 7,659 talks. See Research Pitfall 3.

**_record_failure() function (per D-03):**
- Signature: `_record_failure(talk_id: int, error: str, failed_talks: list) -> None`
- Append `{"talk_id": talk_id, "error": error}` to failed_talks list
- Write entire list to FAILED_TALKS_PATH with `json.dump(failed_talks, f, indent=2, ensure_ascii=False)`
- Use `encoding='utf-8'` on file open
- Write incrementally (after EACH failure) so file survives mid-run kill

**main() function:**
- argparse with `--force` flag (per D-09): `parser.add_argument("--force", action="store_true", help="Re-process already-loaded talks")`
- Record `start_time = time.time()`
- Initialize: `book_cache = fetch_all_books(core_db)`, `chroma_client = get_chromadb_client()`, `embedding_fn = get_embedding_function()`
- Get talks collection for skip check: `talks_col = chroma_client.get_or_create_collection(name=CHROMADB_COLLECTION_NAMES["talks"], embedding_function=embedding_fn)`
- Fetch all GC talk IDs: `all_talk_ids = _get_all_gc_talk_ids()`
- Initialize counters: `pending_bundles: list[TalkBundle] = []`, `processed_since_flush = 0`, `skipped_count = 0`, `failed_count = 0`, `validation_failed_count = 0`, `processed_count = 0`, `failed_talks: list[dict] = []`

**Main loop (per D-01, D-02, D-03, D-04, D-05):**
- `for talk_id in tqdm(all_talk_ids, unit="talk", desc="Pipeline"):`
- Skip check (per D-01): If NOT force mode, call `talks_col.get(ids=[f"talk_{talk_id}"])`. Do NOT pass `include=["ids"]` (raises ValueError per Research Pitfall 4). If `existing["ids"]` is non-empty, increment `skipped_count` and `continue`.
- Inside try/except (per D-02):
  - Call `process_talk_pipeline(content_db, core_db, talk_id, book_cache, PARAGRAPH_CONFIG)`
  - Check `result.success` -- if False, raise `RuntimeError("; ".join(result.errors))`
  - Call `validate_talk(result.metadata, result.paragraphs, result.citations, result.footnotes, db=core_db)` -- pass `db=core_db` for full validation (Research recommendation)
  - If `not validation.is_valid` (per D-04): use `tqdm.write(f"[WARN] talk_id={talk_id} validation failed")`, call `_record_failure(talk_id, f"validation: {validation.errors}", failed_talks)`, increment `validation_failed_count`, `continue`
  - Build bundle: `bundle: TalkBundle = (result.metadata, result.paragraphs, result.citations, result.footnotes, validation)`
  - Append to `pending_bundles`, increment `processed_since_flush` and `processed_count`
  - If `processed_since_flush >= CHROMADB_BATCH_SIZE`: call `load_talk_bundles(pending_bundles, chroma_client, embedding_fn)`, then `pending_bundles.clear()` and reset `processed_since_flush = 0`
- Exception handler (per D-02, D-03): `logger.error("talk_id=%d failed: %s", talk_id, exc)`, `tqdm.write(f"[ERROR] talk_id={talk_id}: {exc}")`, `_record_failure(talk_id, str(exc), failed_talks)`, increment `failed_count`

**Final flush (per D-07):**
- After loop: if `pending_bundles`, call `load_talk_bundles(pending_bundles, chroma_client, embedding_fn)`

**Final summary (per D-06):**
```python
elapsed = time.time() - start_time
print(f"\nRun complete in {elapsed:.1f}s")
print(f"  Total GC talks:    {len(all_talk_ids)}")
print(f"  Processed:         {processed_count}")
print(f"  Skipped (cached):  {skipped_count}")
print(f"  Failed:            {failed_count}")
print(f"  Validation failed: {validation_failed_count}")
if failed_talks:
    print(f"  Failed talks log:  {FAILED_TALKS_PATH}")
```

**__main__ block (per D-05):**
```python
if __name__ == "__main__":
    logging.basicConfig(
        level=logging.WARNING,
        format="%(asctime)s %(levelname)-8s %(name)s: %(message)s",
    )
    main()
```
Use WARNING level so only errors/warnings reach terminal during tqdm run.
