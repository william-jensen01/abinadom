    1. Create `auth/__init__.py` with:


    2. Create `auth/store.py` implementing the KeyStore ABC and SqliteKeyStore. Follow the reference implementation from 14-RESEARCH.md Pattern 1 exactly, with these specifics:
       - `KeyStore` is an ABC (from abc import ABC, abstractmethod) per D-01
       - Abstract methods: `verify_token(self, raw_token: str) -> str | None` and `log_request(self, key_name: str, tool_name: str, timestamp: str) -> None`
       - `SqliteKeyStore.__init__(self, db_path: str)` — stores db_path, calls `_init_db()`
       - `_connect(self) -> sqlite3.Connection` — opens a NEW connection per call (Pitfall 4: thread safety), sets `row_factory = sqlite3.Row`
       - `_init_db(self)` — creates tables via `CREATE TABLE IF NOT EXISTS`:
         - `keys` table: `name TEXT PRIMARY KEY, token_hash TEXT NOT NULL, created_at TEXT NOT NULL`
         - `usage_log` table: `id INTEGER PRIMARY KEY AUTOINCREMENT, key_name TEXT NOT NULL, tool_name TEXT NOT NULL, timestamp TEXT NOT NULL`
         - Add index: `CREATE INDEX IF NOT EXISTS idx_usage_key ON usage_log(key_name)` (per research recommendation)
       - `create_key(self, name: str) -> str` — generates token via `secrets.token_urlsafe(32)`, stores `hashlib.sha256(token.encode()).hexdigest()` with `datetime.now(timezone.utc).isoformat()`, returns raw token (D-06, D-10)
       - `verify_token(self, raw_token: str) -> str | None` — hashes input with SHA-256, looks up by hash, confirms with `hmac.compare_digest()`, returns key name or None (D-11)
       - `log_request(self, key_name: str, tool_name: str, timestamp: str) -> None` — inserts row into usage_log (D-08, D-09)
       - `revoke_key(self, name: str) -> bool` — deletes from keys, returns `cur.rowcount > 0`
       - `list_keys(self) -> list[dict]` — returns list of dicts with "name" and "created_at" (never token_hash), ordered by created_at

    3. Create `tests/test_auth.py` with pytest tests covering all behaviors listed above. Use `tmp_path` fixture for isolated auth.db per test. Import SqliteKeyStore from auth.store.
