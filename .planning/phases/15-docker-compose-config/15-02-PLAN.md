Create `docker-compose.yml` in project root with this exact content:

```yaml
services:
  mcp-server:
    build: .
    ports:
      - "${MCP_PORT:-8000}:${MCP_PORT:-8000}"
    env_file:
      - .env
    volumes:
      - ${CHROMADB_DATA_PATH}:/data/chromadb
      - ${AUTH_DATA_PATH}:/data/auth.db
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 60s
    restart: unless-stopped
    extra_hosts:
      - "host.docker.internal:host-gateway"
```

Key decisions implemented:
- No `version:` key (deprecated in Compose v2 spec — per RESEARCH State of the Art)
- Single service `mcp-server` — no Ollama container (per D-01)
- `env_file: .env` passes OLLAMA_URL, MCP_HOST, MCP_PORT to server.py env var resolution (per D-08)
- Port mapping uses `${MCP_PORT:-8000}` with default fallback (per D-09 variables)
- Bind mount `${CHROMADB_DATA_PATH}:/data/chromadb` (per D-04)
- Bind mount `${AUTH_DATA_PATH}:/data/auth.db` (per D-04)
- Healthcheck via existing `/health` GET endpoint with `start_period: 60s` to handle ChromaDB/ONNX cold start (per RESEARCH Pitfall 1)
- `restart: unless-stopped` (discretion — survives host reboot but stops when explicitly stopped)
- `extra_hosts: host.docker.internal:host-gateway` for Linux host Ollama connectivity (per RESEARCH Pitfall 5)

```bash
# .env.example
# Copy this file to .env and fill in your values.
# DO NOT commit .env to git.
#
# Note: CHROMADB_PATH and AUTH_DB_PATH are fixed inside the container
# at /data/chromadb and /data/auth.db respectively. Do not set them here.

# Ollama — wherever Ollama is running (must be accessible from inside the container)
# On Linux host: use host.docker.internal (requires extra_hosts in compose.yml)
# On LAN: use the machine's IP address
OLLAMA_URL=http://host.docker.internal:11434

# MCP server network configuration
MCP_HOST=0.0.0.0
MCP_PORT=8000

# Host-side data directories (bind mounted into container)
# These directories MUST exist on the host BEFORE running docker compose up.
# Example: mkdir -p /path/to/chromadb /path/to/auth
CHROMADB_DATA_PATH=/path/to/chromadb
AUTH_DATA_PATH=/path/to/auth
```
