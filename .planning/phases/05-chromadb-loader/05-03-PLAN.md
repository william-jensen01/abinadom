    Add the following function to `extractors/phase6_chromadb_loader.py`:

    ```python
    def generate_verification_report(
        client: chromadb.ClientAPI,
        load_result: dict[str, Any],
        n_sample_retrievals: int = 3,
        n_spot_checks: int = 5,
    ) -> dict[str, Any]:
        """Generate post-insertion verification report per LOAD-06.

        Checks:
        1. Record counts for all 4 collections
        2. Sample document retrievals from conference_talk_paragraphs (get by ID, verify content present)
        3. Foreign key spot checks across collections
        4. Skipped talk summary from load_result

        Args:
            client: ChromaDB client with populated collections
            load_result: Return value from load_talk_bundles()
            n_sample_retrievals: Number of sample documents to retrieve and verify (default 3)
            n_spot_checks: Number of foreign key spot checks to run (default 5)

        Returns:
            Dict with keys: "record_counts", "sample_retrievals", "fk_spot_checks",
            "skipped_talks", "summary_text"
        """
    ```

    Implementation details:

    1. **Record counts:** Get each collection via `client.get_or_create_collection(name=...)`, call `.count()`. Store in dict: `{"conference_talks": N, ...}`.

    2. **Sample retrievals:** If `conference_talk_paragraphs` count > 0, retrieve up to `n_sample_retrievals` documents via `collection.get(limit=n_sample_retrievals)`. Verify each has non-empty document text and valid metadata. Store results as list of dicts: `[{"id": id, "document_preview": doc[:100], "has_metadata": bool}]`. If collection is empty, store empty list.

    3. **Foreign key spot checks:**
       - Get up to `n_spot_checks` talk_ids from `conference_talks` collection via `collection.get(limit=n_spot_checks)`, extract `talk_id` from metadata.
       - For each talk_id, query `conference_talk_paragraphs` with `collection.get(where={"talk_id": talk_id}, limit=1)`. Record whether result is non-empty.
       - Get up to `n_spot_checks` paragraph_ids from `conference_talk_paragraphs` via `.get(limit=n_spot_checks)`, extract `paragraph_id`.
       - For each paragraph_id, query `conference_talk_citations` with `collection.get(where={"paragraph_id": paragraph_id}, limit=1)`. Record whether result is non-empty (note: some paragraphs legitimately have no citations — this is informational, not a failure).
       - Store results as: `{"talk_to_paragraph": [{"talk_id": N, "found": bool}, ...], "paragraph_to_citation": [{"paragraph_id": N, "found": bool}, ...]}`

    4. **Skipped talks:** Pass through `load_result["skipped_talks"]` and `len(load_result["skipped_talks"])`.

    5. **Summary text:** Build a human-readable string summarizing all sections. Log it at INFO level. Include it in the return dict as `"summary_text"`.

    Format for summary_text:
    ```
    === ChromaDB Verification Report ===

    Record Counts:
      conference_talks: {N}
      conference_talk_paragraphs: {N}
      conference_talk_citations: {N}
      conference_talk_footnotes: {N}

    Sample Retrievals (conference_talk_paragraphs):
      Retrieved {N} documents, all with valid content and metadata
      ...

    Foreign Key Spot Checks:
      talk_id -> paragraphs: {passed}/{total} resolved
      paragraph_id -> citations: {found}/{total} found (informational)

    Skipped Talks: {N} ({talk_ids})

    =====================================
    ```

    Write integration tests using `chromadb.EphemeralClient()`. Pre-populate collections using `load_talk_bundles()` with 2-3 test bundles, then call `generate_verification_report()` and assert on the returned structure.
