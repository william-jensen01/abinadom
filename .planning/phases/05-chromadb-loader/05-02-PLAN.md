    **load_talk_bundles(bundles: list[TalkBundle], client: chromadb.ClientAPI, embedding_fn=None) -> dict[str, Any]:**
    - Get or create all 4 collections using `client.get_or_create_collection(name=CHROMADB_COLLECTION_NAMES[key], embedding_function=embedding_fn)` (per D-14: pass embedding_fn; in tests it will be None)

    - For each bundle `(metadata, paragraphs, citations, footnotes, validation_report)`:
      - Call `prepare_talk_bundle(metadata, paragraphs, citations, footnotes, validation_report)`
      - If result has empty lists (invalid talk per D-10), append `metadata.talk_id` to `skipped_talks`
      - Otherwise extend the accumulators with the returned records
    - Insert in dependency order (LOAD-04):
      1. `insert_collection(client, talks_collection, ...)` with accumulated talk records
      2. `insert_collection(client, paragraphs_collection, ...)` with accumulated paragraph records
      3. `insert_collection(client, citations_collection, ...)` with accumulated citation records
      4. `insert_collection(client, footnotes_collection, ...)` with accumulated footnote records
    - To split accumulated tuples into separate lists for insert_collection:
      ```python
      docs = [r[0] for r in records]
      metas = [r[1] for r in records]
      ids = [r[2] for r in records]
      ```
    - Return summary dict:
      ```python
      {
          "talks_inserted": len(all_talks),
          "paragraphs_inserted": len(all_paragraphs),
          "citations_inserted": len(all_citations),
          "footnotes_inserted": len(all_footnotes),
          "skipped_talks": skipped_talks,
          "skipped_count": len(skipped_talks),
      }
      ```
    - Log INFO at start: `f"Loading {len(bundles)} talk bundles into ChromaDB"`
    - Log INFO at end: `f"Load complete: {summary}"`
