    **_flatten_metadata(meta: dict[str, Any]) -> dict[str, Any]:**
    - Remove keys where value is None (per D-05)
    - Remove keys where value is an empty list (ChromaDB rejects empty arrays)
    - List[int] -> comma-joined string (e.g., verse_list [32,33,44] -> "32,33,44")
    - List[str] -> pipe-joined string (e.g., extraction_warnings ["a","b"] -> "a|b")
    - str, int, float, bool -> keep as-is
    - All other types -> str(value)

    **prepare_talk_record(metadata: TalkMetadata, annotation_texts: list[str]) -> tuple[str, dict[str, Any], str]:**
    - Document (D-01): `f"{metadata.title}\n\n{metadata.talk_preview}"` if talk_preview is truthy, else `metadata.title`
    - Metadata (D-05): `asdict(metadata)` then `_flatten_metadata()`. Include ALL non-None fields as metadata.
    - Annotations (D-08): if annotation_texts is non-empty, set `meta["annotations"] = "|".join(annotation_texts)`
    - ID: `f"talk_{metadata.talk_id}"`
    - Return `(document, metadata_dict, doc_id)`

    **prepare_paragraph_records(paragraphs: TalkParagraphs) -> tuple[list[tuple[str, dict[str, Any], str]], list[str]]:**
    - Iterate paragraphs.paragraphs
    - Split into two groups: annotation paragraphs (source_type == "annotation") and non-annotation
    - For each non-annotation paragraph (D-02, D-07):
      - Document: `para.text`
      - Metadata: `asdict(para)` then `_flatten_metadata()`
      - ID: `f"para_{para.paragraph_id}"`
    - Collect annotation texts: `[p.text for p in paragraphs.paragraphs if p.source_type == "annotation"]`
    - Return `(list_of_record_tuples, annotation_texts)`

    **prepare_citation_records(citations: TalkCitations) -> list[tuple[str, dict[str, Any], str]]:**
    - For each citation in citations.citations (D-03, D-09):
      - Document: `cite.context_window if cite.context_window else cite.citation_text_raw`
      - Metadata: `asdict(cite)` then `_flatten_metadata()`
      - ID: `f"cite_{cite.citation_id}_{cite.paragraph_id}"`
    - Return list of tuples. All citations included regardless of parent paragraph source_type.

    **prepare_footnote_records(footnotes: TalkFootnotes) -> list[tuple[str, dict[str, Any], str]]:**
    - For each footnote in footnotes.footnotes (D-04):
      - Document: `fn.context_window if fn.context_window else fn.footnote_text_raw`
      - Metadata: `asdict(fn)` then `_flatten_metadata()`
      - ID: `f"fn_{fn.footnote_id}"`
    - Return list of tuples.

    **prepare_talk_bundle(metadata: TalkMetadata, paragraphs: TalkParagraphs, citations: TalkCitations, footnotes: TalkFootnotes, validation_report: ValidationReport) -> dict[str, list[tuple[str, dict[str, Any], str]]]:**
    - If `validation_report.is_valid is False` (D-10): log WARNING with talk_id and errors list, return `{"talks": [], "paragraphs": [], "citations": [], "footnotes": []}`
    - Call `prepare_paragraph_records()` to get paragraph records + annotation_texts
    - Call `prepare_talk_record(metadata, annotation_texts)` to get talk record (includes annotations per D-08)
    - Call `prepare_citation_records()` for citation records (D-09: includes annotation citations)
    - Call `prepare_footnote_records()` for footnote records
    - Return dict with keys "talks" (list with single talk tuple), "paragraphs", "citations", "footnotes"
