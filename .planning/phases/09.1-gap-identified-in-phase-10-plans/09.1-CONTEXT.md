# Phase 9.1: Paragraph Metadata Enrichment - Context

**Gathered:** 2026-03-31
**Status:** Ready for planning

<domain>
## Phase Boundary

Enrich the `paragraphs` ChromaDB collection with talk-level metadata fields (`speaker_name`, `title`, `conference_year`, `conference_month`) so that Phase 10's `search` tool can return the full 6-field result shape (Phase 10 D-01) without a secondary lookup per result.

**What changes:** `prepare_paragraph_records()` gains an optional `talk_metadata` parameter. The caller in `phase6_chromadb_loader.py` passes `metadata` (already in scope). Re-running `run_pipeline.py --force` propagates the enriched fields to all 202,175 paragraph records.

**What does NOT change:** `ParagraphData` model is untouched. No new scripts, no migration. No other collections affected.

</domain>

<decisions>
## Implementation Decisions

### Fix Approach
- **D-01:** Modify `prepare_paragraph_records(paragraphs, talk_metadata=None)` to accept an optional `TalkMetadata` parameter. When provided, inject `speaker_name`, `title`, `conference_year`, `conference_month` into `flat_meta` before appending the record.
- **D-02:** Update the caller at `extractors/phase6_chromadb_loader.py:278` to pass `talk_metadata=metadata` (the `TalkMetadata` object is already in scope at that call site).
- **D-03:** No changes to `ParagraphData` — it remains a paragraph-level model. Enrichment happens at the ChromaDB loading layer only.
- **D-04:** Re-run `run_pipeline.py --force` to propagate enrichment to all 202,175 paragraph records. User runs this on their own schedule.

### Fields to Add
- **D-05:** Inject exactly 4 fields into paragraph metadata: `speaker_name`, `title`, `conference_year`, `conference_month`.
- **D-06:** `session_description` is NOT included — it was explicitly excluded.

### Verification
- **D-07:** Add VER-06 to `scripts/verify_pipeline.py` following the existing VER-01 through VER-05 pattern. VER-06 verifies paragraph metadata enrichment: spot-check a sample of paragraph records and assert all 4 new fields are present and match the corresponding talk record.

### Claude's Discretion
- Exact field injection point within `prepare_paragraph_records()` (before or after `_flatten_metadata`)
- Sample size and selection strategy for VER-06 (e.g., random, first N, one per speaker)
- Whether VER-06 also does a count check (paragraphs with `speaker_name` set vs total) in addition to spot-check

</decisions>
