<objective>
Rewrite server.py from a FastAPI + manual JSON-RPC dispatcher to a native FastMCP server, and rewrite tests/test_server.py to match. This plan delivers a fully working server in local mode (no auth) with both tools, health endpoint, lifespan startup, and CORS. Auth wiring comes in Plan 02.

Purpose: FastMCP replaces ~400 lines of hand-rolled JSON-RPC dispatch, session management, and response formatting with declarative `@mcp.tool()` decorators and native protocol handling. This eliminates the `_FakeMCPCtx` bridge, manual session tracking, and manual method routing.

Output: New `server.py` using `from fastmcp import FastMCP`, rewritten `tests/test_server.py` using `TestClient(mcp.http_app())`.
</objective>

13. **Health endpoint:**
```python
@mcp.custom_route("/health", methods=["GET"])
async def health_endpoint(request: Request) -> JSONResponse:
    """Return server health with live Ollama and ChromaDB reachability checks."""
    status = {"ollama": "reachable", "chromadb": "reachable"}
    http_status = 200

    try:
        ollama_url = resolve_ollama_url()
        ef = get_embedding_function(url=ollama_url)
        ef(["health"])
    except Exception:
        status["ollama"] = "unreachable"
        http_status = 503

    try:
        client = get_chromadb_client()
        for name in CHROMADB_COLLECTION_NAMES.values():
            client.get_collection(name=name)
    except Exception:
        status["chromadb"] = "unreachable"
        http_status = 503

    payload = {"status": "ok" if http_status == 200 else "degraded", **status}
    return JSONResponse(payload, status_code=http_status)
```
