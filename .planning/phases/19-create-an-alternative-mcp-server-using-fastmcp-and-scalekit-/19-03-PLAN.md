<objective>
Clean up project dependencies and deployment configuration. Add `fastmcp` and `scalekit-sdk-python` to Pipfile, remove `fastapi`, regenerate `requirements.txt` from the lockfile, update `.env.example` with ScaleKit env vars, and update `docker-compose.yml` to pass ScaleKit vars to the container.

Purpose: Ensures the project's dependency manifest matches the actual code (FastMCP replaces FastAPI), and deployment configuration supports the new ScaleKit auth model. Without this, Docker builds would fail (missing fastmcp) or install unused packages (fastapi).

Output: Updated `Pipfile`, `Pipfile.lock`, `requirements.txt`, `.env.example`, `docker-compose.yml`.
</objective>

#### Task 3.2 -- Update .env.example and docker-compose.yml for ScaleKit

**Files:** `.env.example`, `docker-compose.yml`

**Action:**

1. **Read `.env.example`** and update:
   - REMOVE `AUTH0_DOMAIN`, `AUTH0_AUDIENCE`, `AUTH0_CLIENT_SECRET` entries
   - ADD ScaleKit entries (with descriptive comments):
   ```
   # ScaleKit OAuth (remote mode only -- leave blank for local/no-auth mode)
   SCALEKIT_ENV_URL=
   SCALEKIT_CLIENT_ID=
   SCALEKIT_CLIENT_SECRET=
   ```
   - KEEP `MCP_BASE_URL` (still needed by RemoteAuthProvider)
   - KEEP `MCP_HOST`, `MCP_PORT`, `CHROMADB_HOST`, `CHROMADB_PORT`, `OLLAMA_URL` and any other existing vars

2. **Read `docker-compose.yml`** and update the mcp-server service `environment` section:
   - REMOVE `AUTH0_DOMAIN`, `AUTH0_AUDIENCE`, `AUTH0_CLIENT_SECRET` entries
   - ADD:
   ```yaml
   - SCALEKIT_ENV_URL=${SCALEKIT_ENV_URL:-}
   - SCALEKIT_CLIENT_ID=${SCALEKIT_CLIENT_ID:-}
   - SCALEKIT_CLIENT_SECRET=${SCALEKIT_CLIENT_SECRET:-}
   ```
   - KEEP `MCP_BASE_URL`, `MCP_HOST`, `MCP_PORT`, `CHROMADB_HOST`, `CHROMADB_PORT`, `OLLAMA_URL` and all other existing entries
   - Do NOT change any other docker-compose.yml configuration (volumes, networks, ports, etc.)

3. Verify no `AUTH0` references remain in `.env.example` or `docker-compose.yml`:
   ```bash
   grep -i "auth0" .env.example docker-compose.yml
   ```
   Should return no matches.
