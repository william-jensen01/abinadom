**Step 1: Update .env.example**

Replace the Auth0 section with ScaleKit section. Replace MCP_HOST/MCP_PORT with FASTMCP_HOST/FASTMCP_PORT.

The updated `.env.example` should contain:

```ini
# .env.example
# Copy this file to .env and fill in your values.
# DO NOT commit .env to git.

# Ollama — wherever Ollama is running (must be accessible from inside the container)
OLLAMA_URL=http://host.docker.internal:11434

# FastMCP server network configuration
# These override FastMCP defaults (127.0.0.1:8000) for Docker deployment
FASTMCP_HOST=0.0.0.0
FASTMCP_PORT=7363

# Host-side data directories (bind mounted into container)
CHROMADB_DATA_PATH=/path/to/chromadb

# ScaleKit OAuth 2.1 (optional — enables OAuth flow for MCP clients)
# Leave ALL THREE blank/unset to run in local mode (no auth).
# Set ALL THREE for remote/hosted mode with ScaleKit JWT validation.
#
# Setup: https://docs.scalekit.com/mcp/overview/
#   1. Create an "MCP Server" resource in ScaleKit Dashboard
#   2. Note the Resource ID -> SCALEKIT_RESOURCE_ID
#   3. Set SCALEKIT_ENVIRONMENT_URL to your ScaleKit environment URL
#   4. Set MCP_BASE_URL to your server's public URL (e.g., Cloudflare tunnel)
SCALEKIT_ENVIRONMENT_URL=
SCALEKIT_RESOURCE_ID=
MCP_BASE_URL=
```

**Remove these lines from old .env.example:**
- `AUTH0_DOMAIN=your-tenant.auth0.com`

- `AUTH_DATA_PATH=/path/to/auth` (auth.db no longer used — SqliteKeyStore removed in Phase 18)
- `MCP_HOST=0.0.0.0` (replaced by FASTMCP_HOST)
- `MCP_PORT=7363` (replaced by FASTMCP_PORT)

The updated docker-compose.yml:


Key change: removed `${AUTH_DATA_PATH}:/data/auth.db` volume mount.
