  </read_first>
  <action>
**1. Update .env.example** — replace Auth0 section with ScaleKit section:

Remove these lines:
```
AUTH0_DOMAIN=your-tenant.auth0.com
AUTH0_AUDIENCE=https://mcp.yourdomain.com
```

Add these lines (replace the Auth0 section):
```
# ScaleKit OAuth (optional — enables JWT auth for remote deployments)
# Leave blank / unset for local mode (no authentication).
# Create a ScaleKit environment at https://app.scalekit.com
SCALEKIT_ENVIRONMENT_URL=https://your-env.scalekit.com
SCALEKIT_CLIENT_ID=skc_your_client_id
SCALEKIT_CLIENT_SECRET=your_client_secret
SCALEKIT_RESOURCE_ID=your_resource_id
```

Keep `MCP_BASE_URL` — it's still used by AuthSettings.resource_server_url:
```
MCP_BASE_URL=https://mcp.yourdomain.com
```

**2. Update docker-compose.yml** — replace Auth0 env var passthrough with ScaleKit:

In the `mcp-server` service `environment` section, replace:
```yaml
      - AUTH0_DOMAIN=${AUTH0_DOMAIN:-}
      - AUTH0_AUDIENCE=${AUTH0_AUDIENCE:-}
      - AUTH0_CLIENT_SECRET=${AUTH0_CLIENT_SECRET:-}
```

With:
```yaml
      - SCALEKIT_ENVIRONMENT_URL=${SCALEKIT_ENVIRONMENT_URL:-}
      - SCALEKIT_CLIENT_ID=${SCALEKIT_CLIENT_ID:-}
      - SCALEKIT_CLIENT_SECRET=${SCALEKIT_CLIENT_SECRET:-}
      - SCALEKIT_RESOURCE_ID=${SCALEKIT_RESOURCE_ID:-}
```

Keep `MCP_BASE_URL=${MCP_BASE_URL:-}` if present.

**3. Remove AUTH_DATA_PATH references** if still present — Phase 18 deleted SqliteKeyStore and auth.db, so no auth data volume is needed. Check if `AUTH_DATA_PATH` is in .env.example or compose and remove if present.
