VER-01 check_counts(client) -> Dict:
  For each of the 4 collection keys (talks, paragraphs, citations, footnotes):
    col = client.collections.use(WEAVIATE_COLLECTION_NAMES[key])
    result = col.aggregate.over_all(total_count=True)
    count = result.total_count
  Derive expected_talk_count from SQLite same as the ChromaDB version:
    talk_rows = core_db.select("SELECT COUNT(*) as cnt FROM talk t INNER JOIN conference_talk ct ON ct.TalkID = t.ID")
    expected_talk_count = talk_rows[0]["cnt"]
  Pass/fail logic identical to ChromaDB version: talks must match exactly, others just > 0.
  Print format matches ChromaDB version but uses PascalCase names and "weaviate" instead of "chromadb".
  Return dict with same shape as ChromaDB version (swap "chromadb" key to "weaviate" in nested dicts).

VER-02 check_semantic_search(client, ef) -> Dict:
  If ef (embedding function) is None or unavailable, skip with reason "no embedding function".
  Otherwise, run 5 sample queries (same queries as ChromaDB version) against
  WEAVIATE_COLLECTION_NAMES["paragraphs"] using:
    col = client.collections.use(WEAVIATE_COLLECTION_NAMES["paragraphs"])
    embedding = ef([query])[0]  # get float vector
    results = col.query.near_vector(near_vector=embedding, limit=5, return_properties=["text", "talk_id", "speaker_name", "conference_year", "title"])
    for obj in results.objects: obj.properties
  Print top 5 results per query. Mark as "manual review" in output.
  If ef is not passed, skip VER-02 with "Ollama required — run with --embedding to enable".
  The script accepts an optional --embedding flag that triggers Ollama embedding. Without it,
  VER-02 is skipped (consistent with VER-02 being "manual review" in the ChromaDB version too).

VER-03 check_metadata_filters(client, ef) -> Dict:
  Test speaker filter: query WEAVIATE_COLLECTION_NAMES["paragraphs"] with
    Filter.by_property("speaker_name").like("*Holland*")
  Test year filter: Filter.by_property("conference_year").equal(2020)
  Test session filter: Filter.by_property("conference_month").equal("April")
  Test compound: year AND season combined with &
  Each filter: fetch up to 5 objects; verify the objects match the filter criteria.
  Print PASS/FAIL per sub-check. Return dict with passed bool and sub-check results.
  Import Filter from weaviate.classes.query.

VER-04 check_fk_integrity(client) -> Dict:
  FK spot-check: sample 10 random paragraph records from WEAVIATE_COLLECTION_NAMES["paragraphs"].
  For each sampled paragraph's talk_id property, verify a corresponding object exists in
  WEAVIATE_COLLECTION_NAMES["talks"] using:
    from weaviate.util import generate_uuid5
    uuid = generate_uuid5(f"talk_{talk_id}")
    obj = client.collections.use(WEAVIATE_COLLECTION_NAMES["talks"]).query.fetch_object_by_id(uuid)
  Count hits and misses. Pass if misses == 0.
  Similarly sample 5 citation records from WEAVIATE_COLLECTION_NAMES["citations"] and
  verify their talk_id exists in the talks collection.
  Print PASS/FAIL per FK check. Return dict with passed bool and details.
  For sampling: use col.query.fetch_objects(limit=10) to get the first 10 objects.

VER-05 check_topics_metadata(client) -> Dict:
  Sample 5 talk records from WEAVIATE_COLLECTION_NAMES["talks"].
  For each, check that the "topics" property is a list (may be empty).
  Check that "title" and "speaker_name" are non-empty strings.
  Print coverage summary. Return dict with passed bool and details.

main() function:
  Parse args: --output (default DEFAULT_REPORT_PATH), --embedding (flag, enables VER-02)
  Set up logging to stderr.
  Connect to Weaviate with context manager.
  Run VER-01 through VER-05 (VER-02 skipped unless --embedding flag set).
  Build report dict with "generated_at", "checks", "overall_passed".
  Write JSON report to --output path.
  Print summary. Exit 0 if overall passed, 1 if any check failed.

if __name__ == "__main__": main()
