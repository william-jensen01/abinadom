Key production differences from benchmark infra:
- ports are "8080:8080" (all interfaces, not 127.0.0.1 bound) so mcp-server container can reach weaviate by service name
- CLUSTER_HOSTNAME: "weaviate-node" (not "weaviate-benchmark")
- Both services on "proxy" network (same external proxy network as mcp-server)
- top-level `volumes: weaviate_data:` section added for data persistence
- mcp-server has `depends_on: weaviate: condition: service_healthy` — prevents mcp-server from
  starting before Weaviate is ready (avoids startup race condition in Plan 06 acceptance test)
