**infra/docker-compose.yml** — Two services (caddy, cloudflared), one network (proxy), two named volumes. Exact content:

```yaml
services:
  caddy:
    image: caddy:2-alpine
    container_name: caddy
    restart: unless-stopped
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile:ro
      - caddy_data:/data
      - caddy_config:/config
    networks:
      - proxy

  cloudflared:
    image: cloudflare/cloudflared:latest
    container_name: cloudflared
    restart: unless-stopped
    command: tunnel --no-autoupdate run
    environment:
      - TUNNEL_TOKEN=${TUNNEL_TOKEN}
    networks:
      - proxy
    depends_on:
      - caddy

networks:
  proxy:
    name: proxy
    driver: bridge

volumes:
  caddy_data:
  caddy_config:
```

Key decisions reflected:
- `caddy:2-alpine` per research standard stack (D-06 routing chain)
- `cloudflare/cloudflared:latest` per research recommendation (monthly releases, `:latest` conventional)
- `restart: unless-stopped` on both services (infra stack is always-on per D-02)
- `depends_on: caddy` on cloudflared — startup hint, cloudflared retries automatically
- `proxy` network created here (not `external: true`) — infra stack owns it (per D-04)
- Caddyfile bind-mounted `:ro` (per D-08)
- `container_name: caddy` and `container_name: cloudflared` for predictable Docker DNS names
- No `version:` key (deprecated in Compose v2, established in Phase 15)

**infra/Caddyfile** — Global options + one site block for MCP. Exact content:

```
{
    admin off
}

mcp.{$DOMAIN} {
    reverse_proxy mcp-server:8000
}
```

Key decisions reflected:
- `admin off` — no config API needed in this deployment
- `{$DOMAIN}` — Caddy environment variable substitution from `DOMAIN` in infra/.env
- `reverse_proxy mcp-server:8000` — Caddy resolves `mcp-server` by container name on the proxy network (per D-07)
- No TLS configuration — Cloudflare terminates TLS at the edge; Caddy receives plain HTTP from cloudflared (per D-06)

**infra/.env.example** — Documents the two required env vars. Exact content:

```dotenv
# Cloudflare Tunnel token (from Cloudflare Zero Trust dashboard)
# Networks > Cloudflare Tunnels > [your tunnel] > Configure > Token
TUNNEL_TOKEN=

# Your root domain (e.g. example.com — NOT mcp.example.com)
# Used in Caddyfile as {$DOMAIN} for subdomain routing
DOMAIN=
```
