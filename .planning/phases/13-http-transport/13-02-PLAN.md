```python
# ---------------------------------------------------------------------------
# Health endpoint — live dependency checks (TRANS-02)
# ---------------------------------------------------------------------------


@mcp.custom_route("/health", methods=["GET"])
async def health_check(request: Request) -> JSONResponse:
    """Return server health with live Ollama and ChromaDB reachability checks."""
    status = {"ollama": "reachable", "chromadb": "reachable"}
    http_status = 200

    # Ollama check: live embedding call (per D-09 — same approach as _check_ollama
    # but without sys.exit on failure)
    try:
        ollama_url = resolve_ollama_url()
        ef = get_embedding_function(url=ollama_url)
        ef(["health"])
    except Exception:
        status["ollama"] = "unreachable"
        http_status = 503

    # ChromaDB check: connect and verify collections exist (per D-09 — reuses
    # startup guard logic pattern without full count validation)
    try:
        path = _resolve_chromadb_path()
        client = chromadb.PersistentClient(path=path)
        for name in CHROMADB_COLLECTION_NAMES.values():
            client.get_collection(name=name)
    except Exception:
        status["chromadb"] = "unreachable"
        http_status = 503

    payload = {"status": "ok" if http_status == 200 else "degraded", **status}
    return JSONResponse(payload, status_code=http_status)
```

CRITICAL constraints:
- Do NOT call `_check_ollama()` directly — it calls `sys.exit(1)` on failure (Pitfall 1 from RESEARCH.md). The health handler must catch exceptions and return 503, not kill the process.
- Do NOT import `uvicorn` or start a separate ASGI app — `@mcp.custom_route` handles registration automatically.
- The `@mcp.custom_route` decorator MUST be placed after `mcp = FastMCP(...)` (Pitfall 4).
- Fresh `chromadb.PersistentClient` per health call is acceptable for Phase 13 scope (Pitfall 2 — low frequency).
- All logging to stderr only — the handler does not need explicit logging since exceptions are caught silently and reflected in the response payload.
