```python
"""
mcpauth resource-server setup for Auth0 JWT verification (Phase 16.1).

Provides build_mcp_auth() which fetches Auth0 OIDC config and returns
an MCPAuth instance configured for resource-server mode.

Design decisions (from 16.1-CONTEXT.md):
  D-01: Auth0 is the Authorization Server.
  D-02: MCP server is a pure Resource Server.
  D-06: Use mcpauth library for JWT validation, metadata, WWW-Authenticate.
  D-08 (REVISED): Static bearer token auth dropped — Auth0 JWT only.
"""
import logging

from mcpauth import MCPAuth
from mcpauth.config import AuthServerType, ResourceServerConfig, ResourceServerMetadata
from mcpauth.utils import fetch_server_config

logger = logging.getLogger(__name__)


def build_mcp_auth(domain: str, resource_url: str) -> MCPAuth:
    """Build an MCPAuth instance in resource-server mode.

    Fetches Auth0's OIDC discovery config (blocking HTTP call — call at
    startup, not per-request). Returns an MCPAuth configured with the
    Auth0 server as the authorization server for the given resource URL.

    Args:
        domain: Auth0 tenant domain (e.g. "my-tenant.auth0.com").
        resource_url: The MCP server's public base URL (e.g.
            "https://mcp.yourdomain.com"). Used in RFC 9728 protected
            resource metadata.

    Returns:
        MCPAuth instance with bearer_auth_middleware() and
        resource_metadata_router() ready for Starlette wiring.

    Raises:
        Exception: If fetch_server_config fails (Auth0 unreachable,
            invalid domain, network error). Let the caller handle this.
    """
    auth_server_config = fetch_server_config(
        f"https://{domain}",
        AuthServerType.OIDC,
    )
    logger.info("Fetched Auth0 OIDC config from %s", domain)

    return MCPAuth(
        protected_resources=[
            ResourceServerConfig(
                metadata=ResourceServerMetadata(
                    resource=resource_url,
                    authorization_servers=[auth_server_config],
                )
            )
        ]
    )
```

Key points:
- NO Auth0JWTVerifier, NO DualTokenVerifier, NO PyJWKClient, NO `from mcp.server.auth` imports
- Single function: `build_mcp_auth(domain, resource_url) -> MCPAuth`
- `fetch_server_config` is a blocking call — called once at module load, not per-request
- Exceptions propagate to caller (server.py handles with try/except)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> MCP API | Untrusted bearer tokens cross here; mcpauth validates JWT signature, audience, issuer, expiry |
| server -> Auth0 JWKS | Server fetches public keys from Auth0 at startup and periodically; trusts Auth0's TLS certificate |
| client -> /health | Public endpoint; no authentication required; returns only operational status |
| client -> Auth0 discovery proxy | Proxies Auth0's OIDC config; no secrets exposed but must not proxy to arbitrary URLs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16.1-01 | Spoofing | bearer_auth_middleware | mitigate | mcpauth validates RS256 JWT signatures against Auth0 JWKS; tokens with wrong audience/issuer/expiry are rejected |
| T-16.1-02 | Tampering | JWT payload | mitigate | RS256 signature verification prevents payload modification; mcpauth handles this internally |
| T-16.1-03 | Information Disclosure | /health endpoint | accept | /health is intentionally public; returns only "ok/degraded" status and dependency reachability — no PII, no secrets, no internal IPs |
| T-16.1-04 | Spoofing | fetch_server_config SSRF | mitigate | AUTH0_DOMAIN is an operator-set env var (not user input); fetch_server_config only contacts `https://{AUTH0_DOMAIN}` — no user-controlled URL construction |
| T-16.1-05 | Denial of Service | Auth0 JWKS unavailability | accept | If Auth0 is down at startup, server logs error and runs without OAuth (static fallback or no auth); mcpauth caches JWKS keys after initial fetch |
| T-16.1-06 | Elevation of Privilege | Static fallback path | mitigate | When AUTH0_DOMAIN is unset, Phase 14 BearerAuthMiddleware enforces static bearer tokens — no unauthenticated access possible in either mode |
</threat_model>
