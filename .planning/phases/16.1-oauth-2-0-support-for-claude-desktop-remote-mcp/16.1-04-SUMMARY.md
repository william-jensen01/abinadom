## Decisions Made

- **mcpauth 0.1.1 API adaptation:** The research notes described a future/different API version (`ResourceServerConfig`, `resource_metadata_router()`). Actual 0.1.1 API: `MCPAuth(server=AuthServerConfig)`, `metadata_route()` (not router), `bearer_auth_middleware` returns `BaseHTTPMiddleware` class. Tests and implementation adapted to match actual API.
- **build_app() factory:** Extracted from `__main__` to make the full app construction testable. Health tests updated to call `build_app()` rather than `mcp.streamable_http_app()` directly.
- **metadata_route() path:** mcpauth's `metadata_route()` serves `/.well-known/oauth-authorization-server` — this is the auth server metadata endpoint (RFC 8414), not the protected resource endpoint (RFC 9728). mcpauth 0.1.1 is authorization-server-metadata focused.
- **AUTH0_AUDIENCE env var kept:** Read but not passed to `build_mcp_auth`; mcpauth handles audience via the OIDC discovery metadata. Kept for forward compatibility.
