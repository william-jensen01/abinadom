    ```python
    """
    OAuth 2.1 token verification for Auth0-issued JWTs.

    Auth0JWTVerifier validates JWTs against Auth0's JWKS endpoint (RS256).
    DualTokenVerifier composes JWT + static bearer token validation (D-08).

    Design decisions (from 16.1-CONTEXT.md):
      D-01: Auth0 is the Authorization Server.
      D-02: MCP server is a pure Resource Server.
      D-08: Both OAuth JWTs and static bearer tokens must be accepted.
      D-11: Token lifetime managed by Auth0, not by server code.
    """
    import logging

    import jwt
    from jwt import PyJWKClient
    from mcp.server.auth.provider import AccessToken

    from auth.store import KeyStore

    logger = logging.getLogger(__name__)
    ```

    `Auth0JWTVerifier` class:
    - `__init__(self, domain: str, audience: str) -> None`
    - Sets `self._audience = audience`
    - Sets `self._issuer = f"https://{domain}/"` (TRAILING SLASH REQUIRED — Pitfall 1 from research)
    - Creates `self._jwks_client = PyJWKClient(f"https://{domain}/.well-known/jwks.json", cache_keys=True, cache_jwk_set=True, lifespan=300)`
    - `async def verify_token(self, token: str) -> AccessToken | None`
    - Calls `self._jwks_client.get_signing_key_from_jwt(token)` to get signing key
    - Calls `jwt.decode(token, signing_key.key, algorithms=["RS256"], audience=self._audience, issuer=self._issuer)`
    - On success: returns `AccessToken(token=token, client_id=payload.get("sub", "unknown"), scopes=payload.get("scope", "").split())`
    - On `jwt.exceptions.PyJWTError`: logs at DEBUG level, returns `None`
    - On any other `Exception`: logs at WARNING level, returns `None`

    `DualTokenVerifier` class:
    - `__init__(self, jwt_verifier: Auth0JWTVerifier, store: KeyStore) -> None`
    - Stores `self._jwt = jwt_verifier` and `self._store = store`
    - `async def verify_token(self, token: str) -> AccessToken | None`
    - First calls `result = await self._jwt.verify_token(token)` — if result is not None, return it
    - Then calls `key_name = self._store.verify_token(token)` — if key_name is not None, return `AccessToken(token=token, client_id=key_name, scopes=[])`
    - If both fail, return `None`
