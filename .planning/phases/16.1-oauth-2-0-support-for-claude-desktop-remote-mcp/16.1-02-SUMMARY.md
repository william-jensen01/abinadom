# Phase 16.1 Plan 02: OAuth Server Wiring Summary

**One-liner:** FastMCP receives AuthSettings + DualTokenVerifier when AUTH0_DOMAIN is set; falls back to standalone BearerAuthMiddleware when not set; Auth0 OIDC discovery proxied at `/.well-known/oauth-authorization-server`.

## What Was Built

**Task 1: Wire OAuth into server.py and add Auth0 discovery proxy**

Modified `server.py` to integrate OAuth 2.1 via the FastMCP constructor:

- Added `from mcp.server.auth.settings import AuthSettings` and `from auth.oauth import Auth0JWTVerifier, DualTokenVerifier` imports
- Removed `from auth.middleware import BearerAuthMiddleware` from top-level imports (deferred to fallback block)
- Added `AUTH0_DOMAIN`, `AUTH0_AUDIENCE`, `MCP_BASE_URL` env var declarations
- Conditional auth init block: when `AUTH0_DOMAIN` and `AUTH0_AUDIENCE` are set, builds `_auth_settings` (AuthSettings) and `_token_verifier` (DualTokenVerifier); otherwise logs "OAuth 2.1 disabled"
- `FastMCP(...)` constructor now receives `auth=_auth_settings, token_verifier=_token_verifier`
- Added `/.well-known/oauth-authorization-server` custom route that proxies Auth0's `openid-configuration` endpoint for Claude client compatibility
- Entry point: falls back to standalone `BearerAuthMiddleware` only when `_auth_settings is None`
- Updated module docstring to mention Phase 16.1

**Task 2: Update .env.example, CLAUDE.md, and Docker config**

- `.env.example`: added `AUTH0_DOMAIN`, `AUTH0_AUDIENCE`, `MCP_BASE_URL` with explanatory comments
- `CLAUDE.md`: added `### auth/` section with `middleware.py`, `store.py`, `oauth.py` entries; added `tests/test_oauth.py` and `tests/test_auth.py` to tests section
- `docker-compose.yml`: no changes needed — `env_file: - .env` already passes all vars through
