Replace the entire file with a `JWKSVerifier` class:

```python
"""
Algorithm-agnostic JWT verification via PyJWT + Auth0 JWKS.

Inspects the JWT header to determine the signing algorithm, then verifies
using the appropriate key material:
  - Asymmetric (RS256/RS384/RS512/PS256/PS384/PS512/ES256/ES384/ES512):
    Fetch public key from Auth0 JWKS endpoint via PyJWKClient.
  - Symmetric (HS256/HS384/HS512): Verify with AUTH0_CLIENT_SECRET env var.
  - none / unknown: Reject with 401.

Design decisions:
  D-01: Auth0 is the Authorization Server.
  D-02: MCP server is a pure Resource Server.
  D-08: Static bearer token auth dropped -- Auth0 JWT only.
"""
```

Class `JWKSVerifier`:
- `__init__(self, domain: str, audience: str, client_secret: str | None = None)`:
  - Store `issuer = f"https://{domain}/"` (Auth0 uses trailing slash in iss claim)
  - Store `audience`
  - Store `client_secret` for HMAC fallback
  - Store `jwks_uri = f"https://{domain}/.well-known/jwks.json"`
  - Create `PyJWKClient(jwks_uri)` instance -- handles JWKS caching with 300s TTL and auto-refresh on unknown kid
  - Define `ASYMMETRIC_ALGORITHMS = ["RS256", "RS384", "RS512", "PS256", "PS384", "PS512", "ES256", "ES384", "ES512"]`
  - Define `SYMMETRIC_ALGORITHMS = ["HS256", "HS384", "HS512"]`

- `verify_token(self, token: str) -> dict | None`:
  - Step 1: `header = jwt.get_unverified_header(token)` -- extract `alg` without signature validation
  - Step 2: `alg = header.get("alg", "")` -- get algorithm
  - Step 3: Route by algorithm:
    - If `alg in ASYMMETRIC_ALGORITHMS`: `signing_key = self._jwks_client.get_signing_key_from_jwt(token)`, then `jwt.decode(token, signing_key.key, algorithms=[alg], audience=self._audience, issuer=self._issuer)`
    - If `alg in SYMMETRIC_ALGORITHMS`: check `self._client_secret` is not None, then `jwt.decode(token, self._client_secret, algorithms=[alg], audience=self._audience, issuer=self._issuer)`
    - If `alg == "none"` or unknown: return None
  - Step 4: On any `jwt.PyJWTError` (expired, bad signature, wrong aud/iss): log warning, return None
  - Return the decoded payload dict on success

**Step 2: Add RFC 9728 protected resource metadata endpoint.**

Add this function to server.py (before build_app):
```python
async def _protected_resource_metadata(request: Request) -> JSONResponse:
    """Serve OAuth 2.0 Protected Resource Metadata (RFC 9728).

    Tells MCP clients which authorization server handles tokens for this resource.
    Required by MCP spec for OAuth discovery.
    Paths: /.well-known/oauth-protected-resource
           /.well-known/oauth-protected-resource/mcp
    """
    if not AUTH0_DOMAIN or not MCP_BASE_URL:
        return JSONResponse({"error": "OAuth not configured"}, status_code=404)

    doc = {
        "resource": MCP_BASE_URL,
        "authorization_servers": [f"https://{AUTH0_DOMAIN}"],
        "bearer_methods_supported": ["header"],
    }
    response = JSONResponse(doc)
    response.headers["Access-Control-Allow-Origin"] = "*"
    response.headers["Access-Control-Allow-Methods"] = "GET, OPTIONS"
    return response
```

**Step 3: Create JWT auth middleware.**

Add a new Starlette middleware class `JWTAuthMiddleware` in server.py (not a separate file -- it is tightly coupled to the verifier instance and server routing):

```python
class JWTAuthMiddleware(BaseHTTPMiddleware):
    """Starlette middleware that enforces Auth0 JWT authentication.

    All routes except PUBLIC_PATHS require a valid JWT in the Authorization header.
    On 401, includes WWW-Authenticate with resource_metadata URL per RFC 9728.
    """

    def __init__(self, app, verifier: JWKSVerifier) -> None:
        super().__init__(app)
        self._verifier = verifier

    async def dispatch(self, request: Request, call_next) -> Response:
        auth_header = request.headers.get("authorization", "")
        if not auth_header.startswith("Bearer "):
            return self._unauthorized("Missing bearer token")

        token = auth_header[len("Bearer "):]
        payload = self._verifier.verify_token(token)
        if payload is None:
            return self._unauthorized("Invalid or expired token")

        return await call_next(request)

    def _unauthorized(self, detail: str) -> Response:
        headers = {}
        if MCP_BASE_URL:
            rm_url = f"{MCP_BASE_URL}/.well-known/oauth-protected-resource"
            headers["WWW-Authenticate"] = (
                f'Bearer resource_metadata="{rm_url}", error="invalid_token"'
            )
        else:
            headers["WWW-Authenticate"] = 'Bearer error="invalid_token"'

        return Response(
            json.dumps({"error": detail}),
            status_code=401,
            media_type="application/json",
            headers=headers,
        )
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Server (Authorization header) | Untrusted JWT crosses from any HTTP client to the MCP server |
| Server -> Auth0 JWKS endpoint | Server fetches public keys from Auth0 over HTTPS |
| Server -> Auth0 OIDC discovery | Server proxies Auth0 metadata for clients |
| RFC 9728 endpoint -> Client | Server tells clients which Auth0 tenant to use |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16.1-01 | Spoofing | JWKSVerifier.verify_token | mitigate | Reject alg="none" explicitly before any decode attempt; whitelist only known algorithms in ASYMMETRIC_ALGORITHMS and SYMMETRIC_ALGORITHMS |
| T-16.1-02 | Spoofing | JWKSVerifier.verify_token | mitigate | Always pass explicit algorithms=[alg] to jwt.decode -- never use unverified header alg without whitelist check first |
| T-16.1-03 | Tampering | JWT header inspection | mitigate | Header inspection (get_unverified_header) is used ONLY to select the algorithm; signature verification via jwt.decode still validates integrity |
| T-16.1-04 | Repudiation | JWTAuthMiddleware | accept | No per-user usage logging in this plan (deferred per CONTEXT.md). JWT sub claim available for future logging |
| T-16.1-05 | Information Disclosure | _protected_resource_metadata | accept | RFC 9728 endpoint is intentionally public -- it must be accessible without auth for the discovery flow to work. Only exposes Auth0 domain (already public) |
| T-16.1-06 | Denial of Service | PyJWKClient JWKS fetch | mitigate | PyJWKClient has built-in 300s cache TTL; does not fetch on every request. On unknown kid, refreshes once then fails -- no infinite retry loop |
| T-16.1-07 | Elevation of Privilege | JWT audience/issuer bypass | mitigate | jwt.decode validates aud and iss claims; JWKSVerifier passes both explicitly. Wrong audience or issuer returns None (401) |
| T-16.1-08 | Spoofing | HMAC (HS256) key confusion | mitigate | HMAC verification requires AUTH0_CLIENT_SECRET env var. If not set, HS256 tokens are rejected (return None). Asymmetric and symmetric paths are strictly separated by algorithm whitelist |
| T-16.1-09 | Tampering | _auth_server_metadata proxy | mitigate | Proxy fetches from Auth0 over HTTPS only (httpx default); response is passed through without modification. Auth0 domain from env var (operator-controlled) |
</threat_model>
