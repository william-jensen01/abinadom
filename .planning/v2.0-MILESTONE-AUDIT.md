### Phase 10

### Phase 11

- **SUMMARY frontmatter incomplete on 11-01-PLAN.md** — `requirements-completed` is empty. INTG-02 is partially covered (11-02-SUMMARY.md lists it). No requirement is lost — gap is cosmetic.

### All Phases

- **Nyquist validation not run** — All 4 VALIDATION.md files have `nyquist_compliant: false` and `wave_0_complete: false`. Nyquist was never run for this milestone. Wave 0 tests exist (test_server.py, test_phase6.py) but the validation contract was never formally completed.

- **Structural note: `_resolve_ollama_url()` double-read** — `server.py` defines `_resolve_ollama_url()` which reads `OLLAMA_URL` from env at lines 76–82. `phase6_chromadb_loader.get_embedding_function()` also reads `OLLAMA_URL` independently at line 321. Both default to `http://localhost:11434`. The error message branch in `_check_ollama()` calls `_resolve_ollama_url()` but the actual connection uses the value from `get_embedding_function()`. No requirement is broken; defaults are consistent. Latent risk: if either default were changed, the displayed error URL could diverge from the attempted URL.
